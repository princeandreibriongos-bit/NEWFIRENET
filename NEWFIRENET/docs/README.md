# FireNet Planning Docs

This folder contains implementation-ready planning documents derived from the approved analytics and public data roadmap.

## Documents

- `internal-priority-widgets.md`
  - defines the first three internal dashboard and analytics widgets to build next
- `public-data-contract.md`
  - defines which FireNet fields are safe for the citizen site and which must remain internal-only
- `public-realtime-modules.md`
  - defines the first public website modules and their recommended backend shape

## Suggested Use

1. Build internal analytics improvements from `internal-priority-widgets.md`
2. Create filtered public endpoints using `public-data-contract.md`
3. Build the citizen-facing website modules using `public-realtime-modules.md`
