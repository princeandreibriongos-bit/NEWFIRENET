Main staff system is not a Vercel app

This page replaces the old 404: NOT_FOUND

You reached the GitHub repo for the employee FireNet system (NEWFIRENET). It needs PHP + MySQL (XAMPP, cPanel, VPS). Vercel only hosts static / Node apps — so the full staff portal cannot run here.

What to use where

  • Civilian portal → Vercel repo firenet-civilian
  • Staff login / dashboard / reports → PHP host or XAMPP (+ ngrok for demos)

Run the main system locally

  • Start XAMPP Apache + MySQL
  • Open /firenet/NEWFIRENET/pages/login.html on localhost
  • For a public demo URL, run ngrok http 80 and use that HTTPS base

If you only wanted the public site

Deploy firenet-civilian on Vercel and set FIRENET_API_BASE to your public PHP root (for example your ngrok URL + /firenet/NEWFIRENET).
